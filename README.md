# SAVIOR — Rwanda AI Cybersecurity & Cybercrime Protection Platform

**Subtitle:** AI-Powered Cybersecurity & Digital Protection Platform for Rwanda

SAVIOR is a comprehensive, defensive cyber resilience platform designed to safeguard Rwandan citizens, micro-merchants, and enterprises against mobile money (MoMo) scams, credential phishing, PIN theft, and unauthorized financial transactions.

---

## 🛡️ The 4 Major Built Features

### 1. SAVIOR Secure Vault (7 Dedicated Compartments)
- **Profile & Identity:** Cryptographically bound personal identification with masked NIDA National ID and location.
- **Security & Sessions:** Active trusted hardware tokens with IP, geolocation, device revocation, and security audit logs.
- **My Incidents:** List of user-submitted cybercrime dockets with SHA-256 evidence seals and status progression.
- **Connected Services:** Simulated integration with Bank of Kigali, I&M Bank, MTN MoMo, and Airtel Money with customizable security protection levels.
- **Transaction Authorizations:** History and pending approval queue for multi-stage financial authorizations.
- **Emergency Recovery:** 12-character cryptographic backup emergency codes with download and copy utilities.
- **Privacy & Biometrics:** AES-256-GCM facial geometry template controls, consent switches, and permanent data deletion.

### 2. 1:1 Face Verification & Liveness Detection
- Local camera stream with responsive biometric geometry scanner.
- 5-step dynamic liveness verification (Positioning, Blinking, Head Movement, Vector Hash Extraction, Cryptographic Storage).
- Anti-spoofing heuristics and fallback to strong emergency backup recovery codes.

### 3. SAVIOR Security Score
- Real-time 0–100 Trust Index calculation based on 6 core factors:
  - Strong Master Password (15 pts)
  - Multi-Factor Authentication Active (20 pts)
  - Biometric Face Vector Enrolled (25 pts)
  - Financial Connections High-Shield (15 pts)
  - Emergency Recovery Codes Saved (15 pts)
  - Verified Identity Profile (10 pts)
- Actionable improvement recommendations that dynamically reward score boosts.

### 4. Financial Transaction Authorization Flow
- 3-tier strong authentication for high-value and sensitive transfers:
  1. **Tier 1:** Master Account Password confirmation.
  2. **Tier 2:** 6-digit Time-based One-Time Passcode (TOTP / SMS simulated OTP).
  3. **Tier 3:** 1:1 Biometric Face geometry matching.
- Explicit watermark: **"SIMULATED FINANCIAL CONNECTION — NO REAL MONEY IS MOVED"**.

## 🔍 Additional Defense Modules

- **AI Threat & Scam Scanner:** Evaluates Kinyarwanda & English SMS messages, phishing URLs, and fraudulent MoMo transfer claims using Gemini 3.7.
- **Incident Reporting System:** Produces SHA-256 digital seals for evidence files and generates public tracking IDs (`SAV-2026-XXXXXX`).
- **Official Law Enforcement Portal:** Simulated case docket manager for the Rwanda Investigation Bureau (RIB) and Rwanda National Police (RNP).
- **Security Operations Center (SOC):** Regional cyber threat heatmap tracking all 30 Rwandan districts with live telemetry.
- **Savior AI Advisor:** Multilingual interactive AI assistant answering questions in Kinyarwanda, English, and French.
